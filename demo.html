One camera. Four sizes.

A safe, static page to try CSS discovery and multi-size grouping. No login, tracking or JavaScript on this page.

Try the extension

After installing Image Scout, open its workspace here and keep Deep CSS scan enabled. This page declares four versions of the same synthetic illustration in CSS. Look for one camera asset with four size variants; the largest supplied file is 614 × 680 pixels. The small site icon may appear separately in the icons/all-assets category.

Preview any version, or choose the highest-resolution download to verify the source dimensions before saving. This sample is an illustration, not a product photograph. It does not require the extension to send data to the developer.
