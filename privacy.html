Image Scout — Privacy Policy

Updated: 16 September 2026. Applies to Image Scout 3.1.

Local processing

Image Scout has no developer-operated image processing server, telemetry, advertisements, account service or cloud AI integration. The extension does not upload your images or browsing records to the developer. Opening the workspace starts page/CSS discovery; visiting a page alone does not start a full scan. Site collection requires an additional explicit action.

Requests to source websites

Reading an image, stylesheet or requested child page contacts that website or CDN and can create normal server access logs. Extension fetches omit explicit credentials. Ordinary image loading in a webpage still follows the browser’s usual website rules. The tool does not bypass login, payment, access restrictions or managed browser policies.

Local storage and deletion

Language, preferences and per-site launcher position are stored in the browser’s extension-local storage. Optional saved-link history is off by default; manual saving also stores links. It holds up to 120 entries with URL, title, time, count and type, not image binaries. Settings and the history view provide deletion controls. Uninstalling removes the extension’s local storage. Current scans and selections remain in memory and are reset when the page changes.

Permissions

HTTP/HTTPS site access supports the launcher and image/CSS discovery across page and CDN hosts. activeTab and scripting open the current-tab workspace after a user action. storage saves local preferences and optional links. downloads saves files through the browser. The extension does not request cookies, browser history, debugger or webRequest permissions. Site access can be restricted in the browser, which may reduce functionality.

Downloads and sensitive links

Generated ZIP archives include sources.json with complete source URLs and diagnostic information. URLs can contain signed or private query parameters. Review this file before sharing an archive. Downloaded files stay wherever you choose to save them and are not removed by uninstalling.

Your choices and copyright

You may hide the launcher, disable deep CSS scanning or live observation, stop collection, clear saved links, and remove the extension. A download does not grant copyright permission or permission to redistribute an image. For support, use the contact information shown on the extension’s store listing.

Support and this documentation website

The publisher is madou1217. Contact us through the public support tracker. GitHub issues are public: never post passwords, API keys, signed URLs, private browsing history or sensitive images. Submit only a sanitized description; response times are not guaranteed.

This documentation website is hosted on GitHub Pages. It adds no analytics, cookies, third-party fonts or executable scripts. The hosting provider may process normal connection metadata to deliver and secure the site. Voluntary support reports are handled through GitHub, separately from the extension. See GitHub’s privacy statement for its handling of hosting and support-account data.

拾图 — 隐私政策

更新日期：2026 年 9 月 16 日。适用于拾图 3.1。

本地处理

拾图没有由开发者运营的图片处理服务器、遥测、广告、账户服务或云端 AI。不会向开发者上传图片或浏览记录。打开工作台后才开始页面与 CSS 扫描；仅访问网页不会启动全页扫描。站点采集需要另外主动开始。

访问来源网站

读取图片、样式表或主动采集的子页面，会访问对应网站或 CDN，并可能产生正常的服务器访问日志。扩展读取省略显式身份凭据；网页普通图片加载仍遵循浏览器通常规则。不绕过登录、付费、访问限制或组织浏览器策略。

本地存储与删除

语言、偏好和各网站入口位置保存在浏览器扩展本地存储中。可选历史默认关闭；手动保存也会记录链接。最多保存 120 条 URL、标题、时间、数量和类型，不保存图片文件。历史页和设置页提供删除入口；卸载扩展会移除扩展本地存储。当前扫描与选择仅保存在内存中，页面变化后重置。

权限

HTTP/HTTPS 网站权限用于入口、页面和跨 CDN 图片/CSS 读取。activeTab 与 scripting 用于用户操作后打开当前标签工作台；storage 保存本地设置和可选链接；downloads 使用浏览器保存文件。不申请 Cookie、浏览历史、debugger 或 webRequest 权限。可以在浏览器中收紧网站访问范围，但部分功能可能受影响。

下载与敏感链接

ZIP 中 sources.json 包含完整来源地址及诊断信息，可能带签名或私密查询参数，分享前请检查。下载文件保留在你选择的位置，不会因卸载扩展自动删除。

选择与版权

可以隐藏入口、关闭深入 CSS 或动态观察、停止采集、清空链接或卸载扩展。下载不授予素材版权或转载许可。支持联系方式以扩展商店页面为准。

支持与本说明站

发布者为 madou1217。可通过公开反馈页面联系。GitHub 议题公开可见，请勿提交密码、密钥、签名链接、私密浏览记录或敏感图片。请只提交脱敏描述；不承诺固定回复时间。

本说明站托管于 GitHub Pages，不添加统计、Cookie、第三方字体或执行脚本。托管方可能处理提供和保护网站所需的正常连接信息。你主动提交的反馈由 GitHub 处理，与扩展本身分开；详情参阅 GitHub 隐私声明。

拾圖 — 隱私權政策

更新日期：2026 年 9 月 16 日。適用於拾圖 3.1。

本機處理

拾圖沒有開發者營運的圖片處理伺服器、遙測、廣告、帳戶服務或雲端 AI。不會向開發者上傳圖片或瀏覽紀錄。開啟工作區後才開始網頁與 CSS 掃描；單純造訪網頁不會啟動全頁掃描。網站擷取需要另外主動開始。

存取來源網站

讀取圖片、樣式表或主動擷取的子頁面時，會存取對應網站或 CDN，並可能留下正常伺服器存取紀錄。擴充功能讀取省略明確的身分憑證；網頁一般圖片載入仍遵循瀏覽器通常規則。不繞過登入、付費、存取限制或組織瀏覽器政策。

本機儲存與刪除

語言、偏好及各網站入口位置儲存在瀏覽器擴充功能本機儲存空間。可選歷史預設關閉；手動儲存也會記錄連結。最多儲存 120 筆網址、標題、時間、數量及類型，不儲存圖片檔案。歷史頁與設定頁提供刪除入口；解除安裝會移除擴充功能本機儲存。掃描及選取僅保存在記憶體，頁面變更後重設。

權限

HTTP/HTTPS 網站權限用於入口、網頁與跨 CDN 圖片/CSS 讀取。activeTab 與 scripting 用於使用者操作後開啟目前分頁工作區；storage 儲存本機設定與可選連結；downloads 透過瀏覽器儲存檔案。不申請 Cookie、瀏覽歷史、debugger 或 webRequest 權限。可在瀏覽器中縮小網站存取範圍，但部分功能可能受影響。

下載與敏感連結

ZIP 內的 sources.json 包含完整來源網址與診斷資訊，可能帶簽章或私人查詢參數，分享前請檢查。下載檔案保留在選定位置，不會隨解除安裝自動刪除。

選擇與著作權

可以隱藏入口、關閉深入 CSS 或動態觀察、停止擷取、清除連結或解除安裝。下載不授予素材著作權或轉載許可。支援聯絡方式以擴充功能商店頁面為準。

本說明站託管於 GitHub Pages，不加入統計、Cookie、第三方字型或執行指令碼。託管方可能處理提供及保護網站所需的一般連線資訊。你主動提交的回報由 GitHub 處理，與擴充功能分開；詳見 GitHub 隱私權聲明。
