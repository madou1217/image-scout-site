Using Image Scout

Open the workspace

On a normal HTTP/HTTPS webpage, click the extension icon, the draggable side launcher, or press Alt + Shift + I (Option + Shift + I on Mac). Browser-internal pages and extension stores do not allow injection. In the extension settings, choose English, Simplified Chinese, Traditional Chinese, or follow your browser.

Scan and choose

Opening the workspace starts discovery. Keep deep CSS enabled to include resources declared in loaded stylesheets, even when not shown on the page. Use the curated, all-resource, SVG and icon filters; uncheck multi-size merging to view original resources separately. Click an image to preview; use its checkbox to select it.

Pick the right version

A multi-size badge opens the discovered variants. The default download verifies pixel dimensions and saves the largest verified version. Save current version deliberately saves the previewed variant. Highest resolution does not promise best compression quality or an undiscovered original. Verification failures are shown rather than silently replacing the file with a smaller image.

Batch and site collection

Choose one highest-resolution file per group or all versions for a local ZIP. Site collection is a separate, manually started workspace: same origin, 0–5 levels, with page limits, pacing and cancellation. It does not execute JavaScript on child pages, so interaction-only resources can be missed. Keep the source tab open while reading and creating the ZIP.

Remove data and troubleshoot

Optional saved-link history is off by default. Delete saved links in History or Settings. Uninstalling removes extension-local preferences but not files you downloaded. If the launcher or downloads fail, check browser site permissions, reload the source page, and disable the old Image Scout userscript to avoid duplicate interfaces. Site authentication, expired signatures and browser policy can still block a resource.

Ask for help safely

Report the extension/browser version, expected result, observed result, and a minimal reproduction on a public non-sensitive page. Remove signed query strings, tokens and personal material from links and screenshots. Never attach an unreviewed sources.json or the full downloaded ZIP.

拾图使用帮助

打开工作台

在普通 HTTP/HTTPS 网页点击扩展图标、贴边入口或按 Alt + Shift + I（Mac 为 Option + Shift + I）。浏览器内部页和扩展商店不允许注入。设置中可选择简体中文、繁体中文、英文或跟随浏览器。

扫描与选择

打开工作台后开始发现图片。保留“深入 CSS”可收集已加载样式表声明但未显示的资源。通过精选、全部、SVG 或图标分类筛选；取消合并多尺寸可逐个查看原始资源。点击图片进入预览，点击复选框才是选择。

保存合适的版本

点击“多尺寸”查看已发现的不同版本。默认下载核对像素尺寸后保存最大版本；“保存当前版本”保存正在预览的那一张。最高分辨率不等于最佳压缩质量，也不代表网站未提供的原图。核对失败会提示，不会悄悄降级。

批量与站点采集

ZIP 可选择每组最高分辨率或全部版本。站点采集独立手动开始，限定同源、0–5 级并设置页数、间隔和停止。不运行子页面脚本，所以仅交互后出现的图片可能无法发现。读取和打包期间保持原标签页打开。

删除记录与排查

自动历史默认关闭；在历史或设置中删除保存链接。卸载会清除扩展本地设置，但不会删除已下载文件。入口或下载异常时检查网站权限、刷新原网页并停用旧拾图油猴脚本，避免重复界面。登录限制、失效签名与浏览器策略仍可能阻止读取。

安全反馈

提供扩展版本、浏览器版本、预期与实际结果，以及普通公开页面的最小复现。链接和截图先删除签名参数、令牌及个人内容；不要上传未检查的 sources.json 或整个下载 ZIP。

拾圖使用說明

開啟工作區

在一般 HTTP/HTTPS 網頁點擊擴充功能圖示、側邊入口，或按 Alt + Shift + I（Mac 為 Option + Shift + I）。瀏覽器內部頁面與擴充功能商店不允許注入。設定可選擇繁體中文、簡體中文、英文或跟隨瀏覽器。

掃描與選取

開啟工作區後探索圖片。保留深入 CSS 可擷取已載入樣式表宣告但未顯示的資源。以精選、全部、SVG 或圖示分類篩選；取消合併多尺寸可逐一查看原始資源。點圖片是預覽，勾選方框才是選取。

儲存合適的版本

點多尺寸查看已發現的不同版本。預設下載驗證像素尺寸後儲存最大版本；儲存目前版本則保存正在預覽的圖片。最高解析度不代表最佳壓縮品質，也不代表網站未提供的原圖。驗證失敗會提示，不會默默改存較小圖片。

批次與網站擷取

ZIP 可選擇每組最高解析度或全部版本。網站擷取需另外手動開始，限定同源、0–5 層，並提供頁數限制、間隔與停止。不執行子頁面腳本，僅互動後出現的圖片可能無法發現。讀取及打包期間請保持來源分頁開啟。

刪除紀錄與排查

自動歷史預設關閉；可於歷史或設定中刪除儲存連結。解除安裝會清除本機設定，不會刪除下載檔案。入口或下載異常時檢查網站權限、重新載入來源頁並停用舊拾圖油猴腳本。登入限制、過期簽章與瀏覽器政策仍可能阻擋讀取。

安全回報

提供擴充功能及瀏覽器版本、預期與實際結果，以及一般公開頁面的最小重現。請先移除網址與截圖的簽章參數、權杖及個人內容；不要上傳未檢查的 sources.json 或完整 ZIP。
